# NOMAD Journeys

Демонстрационный сайт туристической компании авторских путешествий и структурированный каталог туров, на который в дальнейшем будет опираться AI-консультант **NOMAD AI Sales Agent** (это отдельная система, не название компании).

> Все цены, даты выездов, количество мест, профили гидов, контакты и условия оплаты — **демонстрационные**. Список того, что нужно подтвердить перед запуском реальной компании, — в [DEMO_DATA.md](DEMO_DATA.md).

## Что внутри

- 30 туров с подробными программами по дням, организационными деталями, условиями и FAQ: 26 стран, 10 категорий.
- 23 демонстрационных профиля гидов.
- Статический сайт (HTML, CSS, JS без сборки и серверной части): главная, каталог с фильтрами, страница тура, направления, гиды, подбор тура, избранное, о компании, как организуются поездки, бронирование и оплата, безопасность, FAQ, контакты, раздел для гидов-партнёров, страница статуса данных и авторов фотографий.
- Данные в JSON, схема и импорт для PostgreSQL, плоский экспорт для AI-агента.

## Структура

```
data/                  источник истины (редактируется вручную)
  meta.json            бренд, версия данных, признаки демонстрационности
  categories.json      10 категорий
  countries.json       26 стран (id = ISO 3166-1 alpha-2)
  guides.json          23 гида
  company.json         принципы, процессы, оплата, отмена и возврат, безопасность, FAQ, контакты
  images.json          библиотека изображений (источник, автор, лицензия)
  departures.json      выезды: даты, статус, места, цена (оперативные данные)
  tours/<id>.json      один тур = один файл (описание, программа, условия)
scripts/
  build.js             проверка связей + генерация всего ниже
  gen-departures.js    генерация демонстрационных выездов (только для макета)
assets/
  data.js              АВТОГЕНЕРАЦИЯ: данные для сайта (глобальный NJ)
  app.js, styles.css   логика и оформление
db/
  schema.sql           схема PostgreSQL
  seed.sql             АВТОГЕНЕРАЦИЯ: данные для импорта
export/
  catalog.json         АВТОГЕНЕРАЦИЯ: плоский каталог для AI-агента
*.html                 страницы сайта
```

## Как работать с данными

После любых правок в `data/` запустите:

```bash
node scripts/build.js
```

Скрипт проверит ссылки (страна, категория, гид, альтернативы, изображения, число дней в программе, наличие выездов) и пересоздаст `assets/data.js`, `db/seed.sql` и `export/catalog.json`. При ошибке он выведет список проблем и завершится с кодом 1.

Локальный просмотр: `python3 -m http.server 8000` и откройте `http://localhost:8000`.

### Модель данных тура

| Группа | Поля |
|---|---|
| Идентификация | `id` (стабильный, используется в URL), `title`, `country`, `region`, `category`, `format` (`small_group` / `private`), `private_available`, `tags` |
| Основное | `days`, `nights`, `start_point`, `end_point`, `price_from`, `currency`, `single_supplement`, `season` (`months`, `best`, `note`), `group` (`min`, `max`), `difficulty` (1–3), `difficulty_note`, `fitness_requirements` |
| Описание | `short`, `description`, `highlights`, `advantages`, `suitable_for`, `not_suitable_for` |
| Программа | `itinerary[]`: `day`, `title`, `places[]`, `summary`, `activities[]`, `free_time`, `unique_experience` |
| Организация | `accommodation`, `transport`, `meals`, `included`, `excluded`, `requirements`, `equipment`, `restrictions`, `docs_note` |
| Условия | `cancellation_policy` (ссылка на политику в `company.json`); предоплата и срок окончательной оплаты — в `company.json → payment` |
| Связи | `guide` (→ guides), `country` (→ countries), `category` (→ categories), `alternatives[]` (→ другие туры, с причиной), `images` (ключи из images.json) |
| FAQ | `faq[]`: `q`, `a` |

Цены, даты и места **вынесены в `departures.json`**: у выезда есть `price_override` (пусто = базовая цена тура), `seats_total`, `seats_available`, `status`. Их можно обновлять независимо от текстов; в БД это отдельная таблица `departures`.

### Для AI-агента

`export/catalog.json` содержит по одному объекту на тур со всем контекстом: страна, категория, сезон (месяцы и названия), сложность, программа, что включено, требования, FAQ, альтернативы с причинами, гид, ближайшие выезды с ценой и статусом, условия бронирования, признаки демонстрационности. Агент может подбирать туры по интересам, бюджету, сезону, длительности и подготовке, сравнивать и объяснять. Если ничего не подходит, на страницы тура доступны `alternatives`.

Страница `/match.html` показывает тот же принцип на клиенте: она оценивает туры по запросу и объясняет, почему они подходят или чем отличаются.

### PostgreSQL

```bash
psql -d nomad -f db/schema.sql
psql -d nomad -f db/seed.sql
```

Схема проверена на PostgreSQL 15: импорт даёт 30 туров, 289 дней программы, 90 вопросов FAQ, 116 выездов, 23 гида. Основные таблицы: `categories`, `countries`, `guides`, `guide_countries`, `tours`, `tour_days`, `tour_faq`, `tour_alternatives`, `departures`, `cancellation_policies`, `images`, `company_faq`; представление `v_departures` считает итоговую цену выезда.

## Что не реализовано намеренно

- Нет платёжной системы и имитации оформления заказа. Кнопка «Оставить запрос» только формирует структуру запроса (JSON) и сообщает, что backend не подключён.
- Нет отзывов: их можно публиковать только от реальных клиентов.
- Нет сведений о лицензиях, сертификатах, партнёрствах и гарантиях.

## Публикация

Сайт полностью статический и подходит для GitHub Pages, Netlify или любого хостинга. Папка `.nojekyll` отключает обработку Jekyll.
